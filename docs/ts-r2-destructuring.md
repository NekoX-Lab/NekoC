# 浅层解构与数组读取诊断

本轮仅扩展前端语法，复用现有列表、对象堆和每次调用的局部帧。

## 支持

```ts
let a = 1, b = 2;
[a, b] = [b, a];
const { x, y: renamed } = { x: 1, y: 2 };
```

- 数组解构赋值必须独立成句，右侧是没有空洞或 spread 的数组字面量。
  赋值目标为已有变量，可用空位跳过元素。先完整求值右侧一次（包括未使用
  的元素及其副作用），再依次赋值；交换不会读到已经被覆盖的变量。
- 对象解构支持普通 `let`/`const`/`var` 变量声明中的浅层绑定、字面量属性名
  和重命名。保存初始化表达式一次，再按声明顺序读取属性；对象和数组属性
  保持引用身份。一个声明语句中的其他声明维持原顺序。
- 顶层与函数/事件局部声明使用现有初始化和作用域机制。显式可空、可选属性
  沿用 nullable 检查与哨兵表示；不要用 `any` 隐藏对象形状。

## 明确报错

- 对象 rest、默认值、嵌套模式、计算属性名，以及参数/循环头中的对象模式。
- 数组赋值表达式取值、非字面量右侧、空洞/spread、缺失元素、属性赋值目标、
  默认值、rest 和嵌套模式。改用显式临时变量、属性/元素读取及独立赋值。
- 确定为负数、非整数、非有限值的直接数组索引；稳定密集字面量数组上的
  确定越界索引。诊断要求有效索引或带具体备用值的边界检查。
- 数组的字符串属性键（包括对象解构产生的读取）仅支持 `length` 和规范数组
  索引，如 `"0"`；`"01"`、`"-1"`、`"0.5"` 等不会强制转换成列表位置，
  而是明确报错。规范索引同样检查确定越界。普通对象的这些字面量键不受影响。
- 非有限索引的静态求值递归处理一元正负号（如 `-Infinity`、`+NaN`），
  但不把局部变量、参数或内联绑定遮蔽的 `Infinity`/`NaN` 当成内建常量。

动态数组读取和 `at()` 的缺失值仍沿用现有 KN 列表行为，尚未统一为 JS
`undefined`。本次没有新增导出变量、稀疏数组、迭代器或递归对象支持。
