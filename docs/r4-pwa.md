# Web 播放器离线使用

`node tools/build-pages.mjs` 发布的静态 WASM 播放器在 HTTPS（或 localhost）
自动下载运行时缓存。只覆盖 `play/`，不覆盖在线编译器、原生 Rust 后端、
浏览器扩展或自包含导出包。不需要安装到桌面；这不是新增 VM 功能。

## 保存与重新打开

1. 首次联网打开 `play/play.html`，展开“离线作品”，等待“运行时可离线使用”。
2. 导入作品或通过 `?src=` 打开作品，再点“保存当前作品供离线使用”，确认
   不含隐私。素材下载成功并原子写入后，才会显示“作品已保存”。
3. 断网后重新打开同一播放器地址，从下拉列表选作品，点“打开离线作品”。
   离线打开不会自动运行，仍需点开始。`?src=` 是在线输入，不自动缓存该 URL；
   断网时该输入失败后仍可从下拉列表打开已保存版本。
4. 共享设备离开前点“清除已保存作品”；运行时缓存中不含作品。

作品必须手动保存：仅打开、导入、运行或接收编译器消息不会持久化作品。
保存的是导入后的初始项目，不是游戏进度、变量变更、录制、云变量、账户、
设备输入或 API 响应。源码本身可能含敏感文本，无法自动识别，故必须确认，
不要保存私有作品。同源应用依浏览器安全模型可访问 Cache Storage，
这不是加密的隐私保险箱。

仅下载规范造型、音频、视频表的素材，不遍历代码里的任意 URL。下载省略
凭据、禁用 HTTP 缓存、不跟随重定向，要求可读且类型匹配的公开响应；
拒绝 URL 用户名/密码、查询参数、片段、常见 API/私有路径、`private` /
`no-store` 响应及有外部引用的 SVG。跨域素材需要 CORS。嵌入 data 素材
随作品保存。为避免隐藏的外部依赖，SVG 还保守拒绝实体、CSS 转义、
`@` 规则、SMIL 动画及活动内容；并非所有可在线播放的 SVG 都能保存。
网络资源每个最多 16 MiB，单作品 64 MiB，最多 5 个 /
共 128 MiB；超过限制、部分下载失败或配额不足不会加入残缺作品。
隐私模式、禁用 Service Worker 的环境、权限失败时继续在线播放。浏览器
可能回收存储，离线保存不能替代导出备份；外部扩展/云服务离线不可用。

## 更新策略

构建时对 HTML、CSS、全部 JS、WASM 及 SW 策略内容做 SHA-256，作为运行时
缓存版本，并逐文件验证摘要。完整预缓存成功才安装；网络失败或部署文件
混版则旧版仍可使用。当前版本始终
从自身缓存取运行时，避免 JS / WASM 混用。不调用 `skipWaiting()`，新版
等待旧版的全部播放器标签关闭，再次打开才激活；界面会提示。激活后仅清理
同 scope 的旧运行时缓存，保留独立 schema 的作品缓存和其他应用缓存。
首次安装不调用 `clients.claim()`：首次访问的页面继续使用原网络版本，
下次导航才由新 SW 接管；未受控的首次页面仍能通过激活的 SW 显式保存作品。
缓存条目被回收时，在线仅尝试下载与当前摘要一致的资源修复；存储配额不足
仍可使用验证成功的在线响应，不会把新版文件混入旧版。
作品包保留原规范项目（包括 K4 来源元数据），素材以独立 data URL 表保存；
重新打开时先用当前 WASM 重新导入原项目，再覆盖播放器使用的素材 URL。
这样不篡改来源快照，也不把旧运行时的兼容性判断当作当前版本的结果。

这是 NekoC 自有的离线功能，不声称与官方编辑器/播放器的离线策略一致；
官方离线行为**未验证**。回归测试见 `tests/r4-pwa.test.mjs`；浏览器回归：
`NEKOC_PWA_E2E=1 node --test tests/r4-pwa.test.mjs`（需 Playwright Chromium）。
浏览器回归使用真实 Service Worker、Web Worker、WASM 初始化和断网，
但 VM 使用确定性桩；它验证缓存与播放链路，不代表真实作品的 VM 兼容性。
Safari / Firefox 与浏览器主动回收存储后的行为未单独验证。

安装异步工作通过 `event.waitUntil()` 纳入生命周期，且不设置 skip-waiting
标志；版本等待与缓存清理由上述回归测试验证，不作为编程猫官方运行时
行为证据。
