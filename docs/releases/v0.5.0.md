## 下载

**完整包**解压后直接就能用，里面有：

- 本机后端 `web`（带 JIT）和命令行 `nekoc`
- PICKCAT 浏览器扩展（`extension/`）
- 示例作品：`works/` 下有《方界》《Pencraft》《星垒》和积木里的小语言模型，`samples/` 下有小示例和可直接改的模板
- TypeScript 前端和文档

不需要安装 Rust。只运行作品时也不需要 Node.js；用 TypeScript 编译作品需要 Node.js 18 或以上。

| 系统 | 文件 | 启动 |
| --- | --- | --- |
| Windows x64 | `nekoc-0.5.0-x86_64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| Windows ARM64 | `nekoc-0.5.0-aarch64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| macOS Apple Silicon | `nekoc-0.5.0-aarch64-apple-darwin.tar.gz` | 终端运行 `./start.sh` |
| macOS Intel | `nekoc-0.5.0-x86_64-apple-darwin.tar.gz` | 终端运行 `./start.sh` |
| Linux x64 | `nekoc-0.5.0-x86_64-unknown-linux-gnu.tar.gz` | `./start.sh` |
| Linux ARM64 | `nekoc-0.5.0-aarch64-unknown-linux-gnu.tar.gz` | `./start.sh` |

启动脚本会运行本机后端，并在浏览器里打开 <http://127.0.0.1:4173/play>。把 `works/` 里的作品拖进播放器就能玩。

其他文件：

- **`nekoc-pickcat-extension-0.5.0.zip`：** 只有 PICKCAT 浏览器扩展。扩展本身没有变化，版本仍是 0.3.1，装过的不用更新。
- **`nekoc-android-0.5.0.apk`：** Android 客户端，支持 arm64 和 x86_64，需要 Android 10 及以上。装过旧版的可以直接覆盖安装。
- **`fttawa-nekoc-0.5.0.tgz`：** npm 包 `@fttawa/nekoc`，WASM 版编译器和播放器，不需要 Rust。
- **`SHA256SUMS.txt`：** 所有包的校验值。

**在线编译页：** <https://nekox-lab.github.io/NekoC/>，已更新到 0.5.0 的编译器。

**只想把 TypeScript 编译成作品？** 不用下载完整包，也不用克隆仓库：用在线编译页，或者 `npm i @fttawa/nekoc`。

## 主要更新

### 播放器：离线导出、手机触控、双语界面

- **导出离线播放器：** `nekoc export-player 作品.bcmkn --out 我的作品.zip` 会把作品、素材和 WASM 运行器打成一个包。解压后双击 `index.html` 就能玩，不联网、不装任何东西；整个目录也能直接放到任意静态网站上。说明见 [docs/player-export.md](https://github.com/NekoX-Lab/NekoC/blob/v0.5.0/docs/player-export.md)。
- **停止按钮和报错提示：** 作品运行出错时显示看得懂的错误，可以直接重新开始；重新开始会清掉上一次留下的画笔痕迹。
- **手机和平板：** 触摸舞台等同于鼠标操作。打开「显示虚拟按键」会出现方向键和空格、回车、Z、X，可以多键同按。横竖屏、全屏都会按作品比例适配，切后台、旋转屏幕不会卡键。
- **中英双语、键盘可用：** Studio 和播放器都能切换中文 / English（也可以用 `?lang=en`），会记住上次的选择；积木区、标签页、对话框都能只用键盘操作。
- **录制复现：** 播放器可以录下一次操作并导出复现包，`nekoc` 能按复现包逐帧重放出同样的结果。遇到「点了某个地方之后作品出错」的问题时，把复现包发过来就能稳定复现。

### 作品体检报告

导入作品后，Studio 会列出一份体检报告，把每个问题按「能保留导出 / 能执行 / 语义近似 / 尚未验证 / 不支持」分类，并写清在哪个场景、哪个角色、哪个积木，以及影响是什么。点一下就能跳到对应的积木，报告也可以下载。命令行用：

```
nekoc check 作品.bcmkn --report
```

明确不支持的作品退出码为 1，只有近似或未验证的项时退出码为 0。说明见 [docs/import-health.md](https://github.com/NekoX-Lab/NekoC/blob/v0.5.0/docs/import-health.md)。

### TypeScript：Map / Set、位运算、replace，报错更准

```ts
const counts = new Map<string, number>();
for (const word of ["cat", "dog", "cat"]) counts.set(word, (counts.get(word) ?? 0) + 1);
console.log(counts.get("cat"));            // 2

const seen = new Set<number>([1, 2, 2, 3]);
console.log(seen.size);                    // 3

let flags = 0;
flags |= 1 << 3;
console.log(flags & 8, flags >>> 1);       // 8 4

console.log("a-b-c".replaceAll("-", "+")); // a+b+c
const [first, second] = [10, 20];
console.log(first + second);               // 30
```

- **Map 和 Set：** 构造、`set/add/get/has/delete/clear`、`size`、按插入顺序 `for-of` 和 `forEach`。键可以是字符串或数字。
- **位运算：** `& | ^ ~ << >> >>>` 现在可以有变量参与，也支持 `|=` 这类复合赋值。
- **字符串：** 完整的 `replace` / `replaceAll`（支持 `$&`、`$$` 等替换模板和空搜索串），`charAt`、`substring`、`padStart`、`repeat` 等按 JS 规则处理边界。
- **解构：** 顶层和函数里都支持数组 / 对象的浅层解构。
- **报错定位：** 错误指向你自己写的那一行（包括导入的模块和被展开的回调），带代码片段和修改建议，并分成 `syntax`、`types`、`compat`、`project` 四类。`nekoc check --json` 的输出格式也固定下来了，npm 包和浏览器 SDK 返回同样的结构。
- **不支持的写法会明确报错：** 以前 BigInt、tagged template、dynamic import、`using`、逻辑赋值等写法可能被悄悄编译成错误的积木，现在都会在编译时报错，并给出改写建议。async / await 和 Promise 也会明确报错；`setTimeout` 等定时器统一在根工作区调度。哪些能写、哪些不能写，以及各自的替代写法，都整理在 [docs/js-support.md](https://github.com/NekoX-Lab/NekoC/blob/v0.5.0/docs/js-support.md)。

### 命令行

- 帮助全部改成中文，每个子命令都写了用途、参数和选项。
- `--json` 放在子命令前后都可以，输出统一为一个 JSON 文档。
- 退出码统一：0 成功，1 执行或检查失败，2 用法错误。出错时会提示下一步怎么做。

### 新模板

`samples/templates/` 新增几个可以直接复制改的模板：移动和碰撞、菜单与多场景、列表背包，以及进阶版的「菜单 → 收集挑战 → 结算」和可以选格子的背包。可调的参数（标题、目标分数、容量等）都放在文件顶部。

## 兼容性修复

### Kitten N

- PICKCAT 真实作品里常见的几种积木写法、未知的特效选项、引用了已删除角色的侦测积木、各个 KN 版本的 `toolType`，都不会再让作品中止。
- 广播发给大量克隆体时不再中止。
- 变量和列表监视器：开局按保存的状态显示，位置和外观与官方一致。
- 与官方对齐的行为：
  - 文本的边界处理和数字相等判断
  - 画笔起点叠色、重复落笔
  - 等待积木恢复时的帧边界、小数计时的累计
  - `复制列表` 保留共享引用
- 删除克隆或重新开始之后，不再接着执行后面的积木。
- 「绕角色旋转」和碰撞事件里的角色下拉框不再显示成「?」。
- 摄像头不可用时降级继续运行；音频设备出错或卡住时，不会一直卡在等待播放上；跳过已禁用的旧翻译积木。
- 已删除克隆体的绘图、文字造型、气泡会及时释放，长时间运行大量克隆的作品内存更稳定。

### Kitten 4

- 普通算术按官方的十进制规则计算，小数加减乘的结果和官方一致。
- 引用了已删除列表的作品按官方语义运行。
- 与官方对齐的行为：
  - 像素碰撞的采样方式、碰到边缘就反弹
  - 零角度的扭曲滤镜
  - 匿名身份、指针目标、相对场景切换
- 导出 Kitten 4 时，普通 `for` 循环改用通用控制积木。
- 选择问答对话框的布局和按钮松开交互修好了。

### TypeScript 语义修正

- 数组方法的求值顺序、`slice` / `splice` 的边界、回调遍历长度。
- 默认参数的求值顺序。
- 顶层 `Infinity` / `NaN` 常量不再变成 0。
- `Math.max` / `Math.min` / `Number.isInteger` 正确处理 NaN，`Math.hypot` 不再溢出。
- 事件回调重入时，各自的局部变量互不干扰。
- 不安全的类字段更新会报错。

## 性能

- **JIT：** 画笔路径和填充色留在 JIT 里执行，画图密集的作品更快。
- **Kitten 4 十进制运算：** 加、减、乘走精确的快速路径。
- **Web 渲染：** 合并连续的纹理绘制，缓存 Kitten 4 图章；文字造型缓存按占用大小淘汰，不再无限增长。
- **WASM：** 导入作品的响应按引用序列化，大作品打开更快。
- **TypeScript 编译：** 函数内联按展开成本设上限，避免积木数量成倍膨胀；文本长度改用缓存的 UTF-16 计数。

## 稳定性

- 用模糊测试加固了作品导入、积木图装配和虚拟机的资源上限，畸形作品会报错，不会卡死或崩溃。
- 同一个工程放在不同路径下，编译结果完全一样。
- 输入队列过载时不再吞掉鼠标松开事件。

## 已知限制

- **动态数组越界读取：** 得到 `NaN`，JavaScript 里是 `undefined`。能在编译时确定的越界会直接报错。
- **递归深度：** 最多 200 层，JavaScript 会深得多。
- **对象、class 实例和 Map / Set 只分配、不逐个回收：** 重新开始作品时才释放，别在循环里无限新建。
- **不支持 async / await、Promise、generator：** 会报编译错误，替代写法见 [docs/js-support.md](https://github.com/NekoX-Lab/NekoC/blob/v0.5.0/docs/js-support.md)。
- **安装包没有代码签名或公证。** macOS 第一次运行需要在「系统设置 → 隐私与安全性」里允许，Windows 可能会弹出 SmartScreen 提示。
- **Linux 包：** glibc 动态链接，不适用于 Alpine 等 musl 系统。
- **APK：** 仍使用调试签名。
- **Kitten N 不刷新屏幕执行：** 让出边界还没有和官方规则完全对齐。
- **硬件、AI、网络、账户类积木：** 大多只有降级实现。
