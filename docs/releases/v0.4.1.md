## 下载

**完整包**是解压就能用的版本，里面有：

- 本机后端 `web`（带 JIT）和命令行 `nekoc`
- PICKCAT 浏览器扩展（`extension/`）
- 示例作品：`works/` 下有《方界》《Pencraft》《星垒》和积木里的小语言模型，`samples/` 下有小示例
- TypeScript 前端和文档

不需要安装 Rust。只运行作品时也不需要 Node.js；用 TypeScript 编译作品需要 Node.js 18 或以上。

| 系统 | 文件 | 启动 |
| --- | --- | --- |
| Windows x64 | `nekoc-0.4.1-x86_64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| Windows ARM64 | `nekoc-0.4.1-aarch64-pc-windows-msvc.zip` | 双击 `start.cmd` |

## 主要更新

这是一个修复版，重点是让 TypeScript 写的作品能在 **Kitten N 分享播放器**里正常播放，并且运行结果和 JavaScript 一致。

### 普通对象能在分享播放器里运行了

- 0.4.0 里普通对象编译成 `_object_*` 积木，分享播放器不支持这类积木，作品发布后放不了。
- 0.4.1 把对象改成列表存储，生成的作品里不再有 `_object_*` 积木。
- 对象的属性要在对象字面量里一次写全、直接赋初值；对象引用要在声明时初始化。缺失或可选属性、方法、getter/setter 和 spread 会明确报编译错误，不会悄悄生成错的积木。

### 生成的积木都在分享播放器支持范围内

- 条件表达式 `a ? b : c`、`Math.max` / `Math.min` / `Math.trunc` 和布尔转数字不再生成 `logic_ternary`，改用自制报告积木，分支仍然只求值一次。
- 三角函数不再生成 `math_trig_rad`，改用角度积木加弧度换算。
- `JSON.stringify` 只支持常量（数字、字符串、数组）在编译时折叠；其他情况明确报错，因为分享播放器没有对应积木。

### 和 JavaScript 结果一致

用 289 条差分用例对照 JavaScript 检查：254 条结果一致，33 条给出明确的编译错误，只剩 2 条已知差异（见下方已知限制）。主要修了这些：

- **同名变量：** 不同函数、代码块、循环里的同名局部变量不再互相覆盖。以前因为重名直接拒绝的写法，现在能正确编译。
- **递归：** 递归函数（包括没有返回值的函数和互相递归）每次调用都有自己的局部变量，子调用返回后不会读到被改掉的值。
- **默认参数：** 按参数顺序在调用时求值一次。读取其他参数的非常量默认值会明确报错。
- **`&&` / `||` / `??`：** 按 JS 规则短路，右边只在需要时求值。
- **`for` 循环：** 初始化和步进部分可以写逗号表达式，`continue` 之后也会正确执行步进。
- **「能被整除」积木：** 运行时结果按布尔值处理，以前会显示成 `1`。
- **`+` 的类型：** 对 `any` 或数字/字符串混合联合类型做 `+`、`+=` 时明确报错，以前可能被当成数字相加。
- **生成器、正则表达式、字符串 `for...of`：** 给出更清楚的报错和替代写法提示。

### 其他

- 编辑器兼容检查发现并修复了两处积木格式问题：对指定角色广播时的角色 ID，以及「删除列表第几项」积木的连接格式。以前它们可能让官方编辑器打开作品时断开连接。
- npm 包：修正了 `bin` 路径写法，`npm publish` 不再警告。
- 仓库和文档链接改到 NekoX-Lab。

## 已知限制

- **数组越界读取：** 得到 `NaN`，JavaScript 里是 `undefined`。
- **递归深度：** 最多 200 层，JavaScript 会深得多。
- **安装包没有代码签名或公证。** macOS 第一次运行需要在「系统设置 → 隐私与安全性」里允许，Windows 可能会弹出 SmartScreen 提示。
- **Linux 包：** glibc 动态链接，不适用于 Alpine 等 musl 系统。
- **APK：** 仍使用调试签名。
- **Kitten N 不刷新屏幕执行：** 让出边界还没有和官方规则完全对齐。
- **硬件、AI、网络、账户类积木：** 大多只有降级实现。
