## 下载

**完整包**是解压就能用的版本，里面有：

- 本机后端 `web`（带 JIT）和命令行 `nekoc`
- PICKCAT 浏览器扩展（`extension/`）
- 示例作品：`works/` 下有《方界》《Pencraft》《星垒》和积木里的小语言模型，`samples/` 下有小示例
- TypeScript 前端和文档

不需要安装 Rust。只运行作品时也不需要 Node.js；用 TypeScript 编译作品需要 Node.js 18 或以上。

| 系统 | 文件 | 启动 |
| --- | --- | --- |
| Windows x64 | `nekoc-0.4.3-x86_64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| Windows ARM64 | `nekoc-0.4.3-aarch64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| macOS Apple Silicon | `nekoc-0.4.3-aarch64-apple-darwin.tar.gz` | 终端运行 `./start.sh` |
| macOS Intel | `nekoc-0.4.3-x86_64-apple-darwin.tar.gz` | 终端运行 `./start.sh` |
| Linux x64 | `nekoc-0.4.3-x86_64-unknown-linux-gnu.tar.gz` | `./start.sh` |
| Linux ARM64 | `nekoc-0.4.3-aarch64-unknown-linux-gnu.tar.gz` | `./start.sh` |

启动脚本会运行本机后端，并在浏览器里打开 <http://127.0.0.1:4173/play>。把 `works/` 里的作品拖进播放器就能玩。

其他文件：

- **`nekoc-pickcat-extension-0.4.3.zip`：** 只有 PICKCAT 浏览器扩展。扩展本身没有变化，版本仍是 0.3.1，装过的不用更新。
- **`nekoc-android-0.4.3.apk`：** Android 客户端，支持 arm64 和 x86_64，需要 Android 10 及以上。装过旧版的可以直接覆盖安装。
- **`fttawa-nekoc-0.4.3.tgz`：** npm 包 `@fttawa/nekoc`，WASM 版编译器和播放器，不需要 Rust。
- **`SHA256SUMS.txt`：** 所有包的校验值。

**在线编译页：** <https://nekox-lab.github.io/NekoC/>，已更新到 0.4.3 的编译器。

**只想把 TypeScript 编译成作品？** 不用下载完整包，也不用克隆仓库：用在线编译页，或者 `npm i @fttawa/nekoc`。

## 主要更新

### 支持 `null`、`undefined`、可选属性和可选链

现在可以写链表、二叉树这类需要「空」的数据结构，也可以用可选的配置项：

```ts
class ListNode {
  next: ListNode | null = null;
  value: number;
  constructor(value: number) { this.value = value; }
}
let head: ListNode | null = null;
for (let i = 3; i >= 1; i--) {
  const node = new ListNode(i);
  node.next = head;
  head = node;
}
let sum = 0;
for (let p = head; p !== null; p = p.next) sum += p.value;
console.log(sum);                           // 6
console.log(head?.next?.next?.value);       // 3
console.log(head?.next?.next?.next?.value); // undefined

type Options = { speed?: number; name?: string };
const opts: Options = { name: "猫" };
console.log(opts.speed ?? 10, opts.name);   // 10 猫
```

支持的写法：

- **可选属性：** `x?: T`，对象字面量可以省略，读出来是 `undefined`。
- **可空类型：** `T | null`、`T | undefined`，普通对象和 class 字段都可以用，比如 `next: Node | null = null`。
- **可选链：** `a?.b`、`a?.b.c`、`a?.[i]`、`a?.m()`，class 方法也可以。
- **空值合并：** `a ?? b`，以及单独成句的 `a ??= b`。
- **判空：** `x === null`、`x !== undefined`、`x == null`、`if (x)`。判断之后，分支里可以按非空类型直接使用。
- **输出：** `console.log`、字符串拼接、模板字符串和 `String()` 里，空值显示为 `null` / `undefined`，和 JS 一致。

可选链和空值合并的左边只求值一次，左边为空时右边不会执行。生成的作品仍然只用官方积木，能在 Kitten N 分享播放器里播放。没用到这些写法的作品，编译结果和 0.4.2 完全一样。

下面这些写法会明确报编译错误，并提示怎么改：

- 拿 `null` / `undefined` 做算术或大小比较。
- 没有判空就读取可能为空的值，或者用 `x!` 跳过判空。
- 直接输出可能为空的对象引用（要输出其中的标量属性）。
- 在函数调用结果上用 `?.`、`f?.()`，以及把 `??=` 当表达式用。
- 把 `pop()` / `shift()` / `find()` 的结果当 `undefined` 判断。
- `delete obj.x`，`any` / `unknown` 里的空值。

完整说明见 [docs/ts-nullable.md](https://github.com/NekoX-Lab/NekoC/blob/v0.4.3/docs/ts-nullable.md)。

## 已知限制

- **数组越界读取：** 得到 `NaN`，JavaScript 里是 `undefined`。
- **还没有 `Map`：** 可以用数组或对象代替。
- **递归深度：** 最多 200 层，JavaScript 会深得多。
- **对象和 class 实例只分配、不回收：** 别在循环里大量新建。
- **位运算：** 只支持两边都是常数的情况，有变量参与时会报编译错误。
- **安装包没有代码签名或公证。** macOS 第一次运行需要在「系统设置 → 隐私与安全性」里允许，Windows 可能会弹出 SmartScreen 提示。
- **Linux 包：** glibc 动态链接，不适用于 Alpine 等 musl 系统。
- **APK：** 仍使用调试签名。
- **Kitten N 不刷新屏幕执行：** 让出边界还没有和官方规则完全对齐。
- **硬件、AI、网络、账户类积木：** 大多只有降级实现。
