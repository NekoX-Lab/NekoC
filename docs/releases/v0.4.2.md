## 下载

**完整包**是解压就能用的版本，里面有：

- 本机后端 `web`（带 JIT）和命令行 `nekoc`
- PICKCAT 浏览器扩展（`extension/`）
- 示例作品：`works/` 下有《方界》《Pencraft》《星垒》和积木里的小语言模型，`samples/` 下有小示例
- TypeScript 前端和文档

不需要安装 Rust。只运行作品时也不需要 Node.js；用 TypeScript 编译作品需要 Node.js 18 或以上。

| 系统 | 文件 | 启动 |
| --- | --- | --- |
| Windows x64 | `nekoc-0.4.2-x86_64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| Windows ARM64 | `nekoc-0.4.2-aarch64-pc-windows-msvc.zip` | 双击 `start.cmd` |
| macOS Apple Silicon | `nekoc-0.4.2-aarch64-apple-darwin.tar.gz` | 终端运行 `./start.sh` |
| macOS Intel | `nekoc-0.4.2-x86_64-apple-darwin.tar.gz` | 终端运行 `./start.sh` |
| Linux x64 | `nekoc-0.4.2-x86_64-unknown-linux-gnu.tar.gz` | `./start.sh` |
| Linux ARM64 | `nekoc-0.4.2-aarch64-unknown-linux-gnu.tar.gz` | `./start.sh` |

启动脚本会运行本机后端，并在浏览器里打开 <http://127.0.0.1:4173/play>。把 `works/` 里的作品拖进播放器就能玩。

其他文件：

- **`nekoc-pickcat-extension-0.4.2.zip`：** 只有 PICKCAT 浏览器扩展。扩展本身和 0.4.1 相同，版本仍是 0.3.1，装过的不用更新。
- **`nekoc-android-0.4.2.apk`：** Android 客户端，支持 arm64 和 x86_64，需要 Android 10 及以上。装过旧版的可以直接覆盖安装。
- **`fttawa-nekoc-0.4.2.tgz`：** npm 包 `@fttawa/nekoc`，WASM 版编译器和播放器，不需要 Rust。
- **`SHA256SUMS.txt`：** 所有包的校验值。

**在线编译页：** <https://nekox-lab.github.io/NekoC/>，已更新到 0.4.2 的编译器。

**只想把 TypeScript 编译成作品？** 不用下载完整包，也不用克隆仓库：用在线编译页，或者 `npm i @fttawa/nekoc`。

## 主要更新

### 支持 class

现在可以用 TypeScript 的 `class` 写作品，编译出来的作品仍然只用官方积木，能在 Kitten N 分享播放器里播放。

```ts
abstract class Animal {
  constructor(public name: string) {}
  abstract sound(): string;
  get label(): string { return this.name + ":" + this.sound(); }
}
class Cat extends Animal { sound(): string { return "meow"; } }
class Dog extends Animal { sound(): string { return "woof"; } }

const zoo: Animal[] = [new Cat("小花"), new Dog("旺财")];
for (const a of zoo) console.log(a.label); // 小花:meow、旺财:woof
```

支持的写法：

- **字段和构造函数：** 字段初始值、`constructor`、参数属性（`constructor(public x: number)`），初始化顺序和 JS 一致。
- **方法和 `this`：** 方法可以有返回值，可以互相调用，也可以递归。
- **继承：** `extends`、`super(...)`、`super.method()`、`abstract`。子类可以重写父类方法，父类类型的变量和数组里放子类实例时，会按实际类型调用对应的实现。
- **`instanceof`：** 可以判断类型，判断后的分支里能直接用子类的成员。
- **getter / setter：** 包括复合赋值（`obj.p += 1`）和子类重写。
- **static：** static 字段和 static 方法。

实例和普通对象一样存放在列表里，变量里保存的是一个数字句柄，所以别名、引用比较、传参和返回的行为都和 JS 一致。

下面这些写法会明确报编译错误，并提示怎么改：

- `#` 私有字段、索引签名、动态成员名。
- 把方法当值用（`const f = obj.m`、`.bind` / `.call` / `.apply`）。
- 泛型 class 或方法、方法重载、async / generator 方法。
- class 表达式、装饰器、mixin，继承 `Array` / `Error` / `Map` 这类内置类型。
- static 成员里的 `this`、static 块、static getter/setter。
- 跨文件继承 class。
- 构造期间调用可能被子类重写的方法。

完整说明见 [docs/ts-classes.md](https://github.com/NekoX-Lab/NekoC/blob/v0.4.2/docs/ts-classes.md)。

### 修复

- **`console.log` 多个参数：** `console.log(a, b)` 以前只输出第一个参数，现在和 JS 一样用空格连接全部参数。
- **示例 `samples/unit_tests.ts`：** 以前用了编译器不支持的写法，编译会失败，现在已修正。另外加了测试，保证所有示例都能通过编译检查。

### 开发流程

- PR 的 CI 现在也会打包 npm 包，并在临时目录里安装运行一遍。以前这一步只在打 tag 发版时才跑。

## 已知限制

- **数组越界读取：** 得到 `NaN`，JavaScript 里是 `undefined`。
- **递归深度：** 最多 200 层，JavaScript 会深得多。
- **对象和 class 实例只分配、不回收：** 别在循环里大量新建。
- **位运算：** 只支持两边都是常数的情况，有变量参与时会报编译错误。
- **安装包没有代码签名或公证。** macOS 第一次运行需要在「系统设置 → 隐私与安全性」里允许，Windows 可能会弹出 SmartScreen 提示。
- **Linux 包：** glibc 动态链接，不适用于 Alpine 等 musl 系统。
- **APK：** 仍使用调试签名。
- **Kitten N 不刷新屏幕执行：** 让出边界还没有和官方规则完全对齐。
- **硬件、AI、网络、账户类积木：** 大多只有降级实现。
