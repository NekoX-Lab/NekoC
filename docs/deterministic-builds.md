# 可复现的 Kitten N 编译输出

同一版本的 NekoC、同一 TypeScript 依赖版本、同一组源文件内容与相对目录结构、
同一模板和编译选项，应生成**逐字节一致**的 `.bcmkn`。支持整个工程移动到其他
绝对目录，在不同工作目录调用，并使用相对或绝对入口路径、不同输出文件名。
构建时间、机器目录和进程的随机状态不参与生成名称。

## 实现

- 积木 ID 继续使用每次编译重置的计数器；资源与变量 ID 继续使用现有确定性分配器。
- 六个 TS 降级阶段（词法绑定、方法、类、继承、可空值、Map/Set）的内部名称盐，
  使用相对于**入口文件所在目录**的模块路径，统一使用 `/`，不再哈希绝对机器路径。
- 导入模块保留完整相对目录，例如 `../left/util.ts` 与 `../right/util.ts`，
  不只使用文件名，避免把同名模块合并到同一个生成名称空间。
- 保留 AST 的真实文件名与工作区报告的 `source`，保证导入解析和错误诊断可定位。
  这些诊断字段不是成品 `.bcmkn` 的持久化来源。
- 不重排用户数组、Map/Set 条目、场景、角色或脚本，避免为追求稳定而改变语义。

## 范围

入口文件名也是输入：它决定默认作品名称和入口名称盐。移动工程但保持内部布局
属于保证范围；重命名入口或调整模块布局不要求保持相同字节。自定义模板的全部
内容、显式资源 URL 和源代码中的路径字符串同样是输入，不会被擦除或重写。

运行时的随机数、时间、联网资源与编译输出确定性是不同概念；不保证运行轨迹一致。
工作区 JSON、诊断、IR/分析旁路报告可能保留绝对来源路径，不属于成品字节保证。
跨编译器/TypeScript 版本不保证一致；现有文件盐仍使用原来的有限位宽哈希，
不新增任意模块集合的数学无碰撞保证。
例如相对模块名 `msn4d7q.ts` 和 `mpphc9o.ts` 的 FNV32 文件盐均为
`2086279340`；两者都包含被提升的同名局部函数时，可能报重复函数定义。
这是已复现的兼容性限制，并非只有理论风险；工程级命名空间消歧尚未实现。

## 回归验证

- `tests/r2-determinism.test.mjs`：六个降级阶段、反复编译、工程移动、同名导入模块、
  Windows/POSIX 文件名、浏览器虚拟路径，以及诊断真实位置。
- `tests/r2_determinism.rs`：独立 CLI 进程编译仓库示例和组合用例，
  分别比较 JSON 结构与原始字节，覆盖普通/优化构建、不同 cwd、相对/绝对入口；
  导入案例还校验执行结果，防止通过误合并名称获得表面上的稳定。
- `tests/fixtures/r2-determinism.ts`：无需第三方作品的组合样例，可用于
  `node tools/editor-compat.mjs <生成的作品.bcmkn>` 官方编辑器兼容检查。

## 官方编辑器实测

2026-11-19 使用 `tools/editor-compat.mjs --channel msedge`，在
`https://kn.codemao.cn/editor` 的 0.27.4 编辑器中加载本次生成的
`block_let`、`custom_procedures`、`multi_screen` 和组合用例。四者均为
`ok: true`，`issues: []`，`pageErrors: []`，分别检查 18、7、17、2507 个积木。
当次主包为
`https://creation.bcmcdn.com/neko/web/release/static/js/main.bfc86683.js`。
此证据只说明这些生成作品的编辑器结构兼容，不等同于完整运行语义认证。
