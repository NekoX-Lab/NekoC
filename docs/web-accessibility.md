# Web 播放器与 Studio 的可访问性和界面语言

播放器 `/play` 与 Studio `/` 的语言选择器支持中文和 English。默认中文；
`?lang=en` / `?lang=zh-CN` 优先于本地保存的选择。切换立即生效并保存到
`neko-language`；浏览器禁用存储时仍可切换，未知语言参数被忽略；无有效保存值时回退为中文。
切换不会重新导入作品或启动运行时，也不会覆盖正在编辑的 JSON 草稿。

`web/i18n.js` 集中保存两种语言的界面文案、积木名称和字段名称。HTML 通过
`data-i18n` 及属性变体声明绑定，动态文案使用 `t(key, values)`。占位参数
只进入 `textContent` 或普通属性，不作为 HTML 解析。新增模块同时由本地
Web 后端、Pages 构建和浏览器扩展构建分发。

作品名称、用户输入、作品输出和后端诊断保持原文。现有日志和已经显示的错误
保留产生时的语言。舞台内作品对话框、底层设备/媒体错误和浏览器扩展自身界面
尚未全部纳入词典，这部分后续继续整理。

键盘操作：

- Tab / Shift+Tab 在控件之间移动；舞台不会拦截 Tab。
- 分类和积木标题使用原生按钮，Enter / Space 激活；`aria-pressed` 表示选择。
  选中积木后从积木库追加指令；字段按 Enter 提交后保留焦点，Tab / Shift+Tab
  提交后按原生顺序移动到相邻控件，不重建正在编辑的字段。角色属性也遵循此规则。
- 表达式可逐层展开；字段提交、撤销 / 重做及语言切换保留各层展开 / 折叠状态。
- 工作区页签支持左右方向键、Home / End；页签和面板通过 ARIA 关联，
  非活动页签不进入 Tab 顺序。重复激活源码页签不会丢弃草稿。
- 播放器的性能设置按钮展开/折叠设置；报告使用原生模态对话框，Escape 关闭，
  焦点返回报告按钮。关闭错误提示后焦点返回导入按钮。
- 舞台、滚动面板、按钮、输入框和选择器都有可见焦点。状态区使用 `role=status`，
  Studio 日志使用 `role=log`；高频性能数字不作为 live region 播报。

浅色 Studio 的次级文字和深色播放器的提示文字调整为更高对比度，移除分支提示
的低透明度。浏览器测试按实际计算样式验证代表性正文达到 4.5:1；这不等于
完整 WCAG 认证，作品自己的画面内容不在此范围内。

验证命令（Windows，先安装 Playwright 或指定已有安装）：

```bash
bash E:/nekoc-wt/_cargo.sh build --bin web
NEKOC_A11Y_E2E=1 NEKOC_NODE_MODULES=<playwright所在node_modules> node --test tests/r3-a11y-browser.test.mjs
```

测试使用仓库自有 K4 fixture、真实 Rust HTTP/WebSocket 后端与 WebGL，覆盖键盘
编辑/播放、确切的正反向焦点目标、两层表达式提交及展开状态、撤销 / 重做、
语言持久化和存储拒绝、JSON 草稿、移动布局及对比度。
通用测试还校验词典参数一致性和静态文本绑定。此改动不涉及官方 VM 行为一致性；
没有将本地 UI 测试视作官方行为证据。
